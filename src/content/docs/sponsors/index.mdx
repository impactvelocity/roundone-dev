RoundOne was built for the [Nebius x NVIDIA Global AI Hackathon](https://nebiusglobalaihackathon.devpost.com/) on Devpost. The hackathon asks every project to run on Nebius Token Factory or Nebius AI Cloud and to use at least one NVIDIA open model. RoundOne uses the sponsors' tools for the work an agent is good at: building repos, reading code, visiting demos and checking claims. Judges keep the calls about the ideas.

## Sponsor tech in RoundOne

| Sponsor | What RoundOne uses | Where it does the work |
| --- | --- | --- |
| [Nebius Token Factory](/docs/sponsors/nebius-token-factory) | One OpenAI-compatible API for every model call, with schema-enforced JSON and embeddings | Agent reviews, double checks, project summaries, Chat, chat search |
| [Nebius Sandboxes](/docs/sponsors/nebius-sandboxes) | VM-isolated sandboxes that clone, install, build and test each repo | The **Sandbox run** mechanism and the agent's `runCommand` tool |
| [NVIDIA Nemotron](/docs/sponsors/nvidia) | Nemotron 3.5 Lightning, Nemotron 3 Super 120B and Nemotron 3 Ultra 550B | The agent's three model tiers and Chat's Fast and Smart modes |
| [Tavily](/docs/sponsors/tavily) | Extract, crawl and search | The **Web scraper** mechanism, the agent's web tools, Chat's index and web lookups |
| [Devpost](/docs/sponsors/devpost) | The hackathon's home: rules, submissions, judges and prizes | Projects come in from a Devpost export through the [Intake API](/docs/reference/intake-api) |

## How they fit together

1. **Devpost** collects the submissions. An organizer exports them and sends them to RoundOne through the Intake API.
2. When judging starts, the agent reviews each project one criterion at a time. Each criterion's mechanisms gather the evidence:
   - **Sandbox run** clones the repo into a **Nebius Sandbox**, installs, builds and runs the tests.
   - **Web scraper** reads the live demo with **Tavily**.
   - **Code scraper** searches the repo for the packages and calls the organizer listed, such as the Token Factory API.
3. An **NVIDIA Nemotron** model, served through **Token Factory**, reads the evidence, investigates with tools on the larger tiers, and returns its verdict as strict JSON.
4. When the agent is unsure, a bigger Nemotron model judges the same evidence again.
5. Judges score the ideas. In Chat, organizers ask questions across every project, answered by Nemotron over a search index built with Token Factory embeddings and Tavily.

## Keys to set

Each sponsor's tools need one key in your environment. [Configuration](/docs/reference/configuration#ai-models-and-sandboxes) lists every variable.

| Variable | Sponsor | Without it |
| --- | --- | --- |
| `NEBIUS` | Nebius Token Factory | No agent reviews, chat or sandboxes. |
| `NEBIUS_PROJECT_ID` | Nebius Sandboxes | Sandbox runs can't start. The rest of the agent works. |
| `TAVILY` | Tavily | Web steps are skipped, and the agent notes "TAVILY isn't set". |

The NVIDIA models need no key of their own: Token Factory serves them with the `NEBIUS` key.
