Nebius

Models and compute, one account

One API key and project ID cover every model call and every sandbox.

Nebius Sandboxes

Runs the code

  1. A node:22 base image
  2. The repo, cloned once per project
  3. A fork of it for each step
  4. Install, build and test

VM-isolated. Every command saves a new image, like a commit, so one step's installs never touch another's.

The inspect API greps and reads files without starting a VM.
Nebius Token Factory

Serves every model

An OpenAI-compatible API, with guided decoding for strict JSON.
