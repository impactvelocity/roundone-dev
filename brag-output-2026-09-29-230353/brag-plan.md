# RoundOne: Devpost video, animated intro (version 2)

**Format:** landscape 1920×1080 at 30fps. **Length:** a 28.0s intro (14 bars at 120 BPM), followed by the screenshot demo, which this plan doesn't cover. **Tone:** arcade-cinematic and fast. It uses the launch film's look, with a hard cut or wipe on every bar that matters. **Voice:** a brisk read of 66 words (about 160 wpm), with key words on screen so the intro still works muted. **Budget:** keep the demo to 2:27 or less, so the whole video stays at or under 2:55 against the 3:00 limit.

The full-length version 1 plan is in `brag-output-2026-09-29-223245/brag-plan.md`.

## The questions first

- **What is it?** Open-source, self-hosted hackathon judging. The RoundOne agent does round one, and people judge the ideas.
- **Who is it for?** Teams that run hackathons, and their judges, starting with the judges of this hackathon.
- **What sets it apart?** The agent uses each sponsor for what it's good at. Nebius Sandboxes run, test and search the code. Tavily reads the live web. NVIDIA Nemotron on Nebius Token Factory checks every claim. The agent informs the judging and leaves the decision to people.
- **Visual hook:** "Hi, judges." over the night sky, then 1,500 pixel squares flood the frame.
- **Share caption:** "The judges of this hackathon have 1,500+ projects. RoundOne's agent runs every repo in a Nebius Sandbox, reads the live web with Tavily and checks every claim with NVIDIA Nemotron, so judges can spend their time on the ideas."

## Angle

Talk to the judges watching, get to the problem and the Nebius-powered answer as fast as possible, then hand off to the demo.

- **Hook (0:00–0:03):** "Hi, judges. Fifteen hundred projects."
- **Reveal (0:08):** the ROUND 1 slam lands on the music drop, and RoundOne arrives as open-source judging whose agent takes round one.
- **Highlight:** the RoundOne agent sits at the center of the frame and puts each sponsor to work in turn: Nebius Sandboxes, then Tavily, then NVIDIA Nemotron on Token Factory.
- **Punchline:** "The agent checks. Judges decide."
- **Handoff:** an 8-bit **How it works ▸** button gets pressed, and a pixel wipe opens onto the first demo screenshot.
- **One project runs through the whole intro:** #042 Repo Whisperer, the sample project from the landing page. In scene 2 its checks wait for a tired judge, in scene 4 the agent runs them all, and in scene 5 its verdict becomes the agent's half of the split.
